# POKÉMON CHAMPIONS PARTY(포챔스 파티 스크린샷 제작 페이지)

**Pokémon Champions** 규격(`Lv.50` · `6V` 고정 · `SP` 최대 `66`)에 맞춰 포켓몬 파티 시트를 작성하고 `16:9` PNG 이미지로 저장할 수 있는 웹 애플리케이션입니다.

> 별도 빌드나 백엔드 서버 없이 정적 HTML/CSS/JS로 동작하며, [GitHub Pages](https://lsaac55151.github.io/poke-party/)에서 바로 실행할 수 있습니다.

---

## 주요 기능

### 1. 게임 스샷 자동 인식 (`Ctrl+V` → 쇼다운 · 시트 즉시 반영)
- Pokémon Champions 인게임 파티 화면의 **`[능력]` 탭**과 **`[스테이터스]` 탭** 스크린샷(**한국어 · 일본어 · 영어**)을 화면 어디서나 **`Ctrl+V`**로 붙여넣거나 드래그 앤 드롭·파일 선택으로 불러올 수 있습니다.
- 서버 전송이나 API 키 없이 **브라우저 로컬(ONNX Runtime Web WASM + PaddleOCR)**에서 직접 문자를 인식하고, 종족값/Lv.50 공식·성별·타입 색상으로 폼과 능력치(SP `0~32`)/성격을 교차 검증·보정합니다. (일본어 UI 선택 시 일본어 OCR이 자동 활성화되며, 모달 내에서도 `KO / EN` ↔ `JP` 전환 가능)
- `[능력]` 스샷과 `[스테이터스]` 스샷을 순서 상관없이 입력해도 자동으로 저장·병합되어(`localStorage` 유지) **쇼다운 텍스트 변환 및 16:9 시트에 바로 반영**됩니다.

### 2. 다국어 쇼다운 텍스트 입력 / 복사
- **한국어 · 일본어 · 영어** Pokémon Showdown 포맷을 자동으로 인식해 파티를 불러옵니다.
- **`.txt` 파일 열기** 및 **화면 드래그 앤 드롭**으로 로컬 파티 파일을 바로 불러올 수 있습니다.
- 기존 252 노력치(EV) 기반 Showdown 텍스트를 붙여넣으면 Pokémon Champions 기준 **SP(개별 최대 `32` · 총합 최대 `66`)**로 자동 환산합니다.
- 작성한 파티를 영문 쇼다운 포맷으로 즉시 복사할 수 있습니다(`쇼다운 복사`).

### 3. Lv.50 · 6V 고정 SP 계산 & 개별 포켓몬 편집
- **개별 포켓몬 편집 / 새 파티 짜기** 모달에서 포켓몬·성격·특성·도구·기술 4칸·SP 분배를 직접 편집할 수 있습니다.
- 마우스 클릭 및 **드래그 조작**을 지원하는 SP 슬라이더로 각 능력치의 SP(`0~32`)와 실능을 실시간으로 조정합니다.
- 전용 메가스톤 장착 시 메가진화 폼 자동 전환 및 빠른 장착 버튼을 지원합니다.
- 내장 데이터: 포켓몬(메가진화 포함 1,366종), 기술(864종), 도구(584종), 특성(317종) 다국어 데이터 및 도구 아이콘 스프라이트 포함.

### 4. 시트 커스터마이징
- **표시 언어 5종**: `한국어`, `日本語 (일본어)`, `English (영어)`, `한·일 병기`, `한·영 병기`
- **시트 테마 3종**:
  - `포챔스 인게임 (퍼플·크림골드)`
  - `포챔스 로고 (네이비·골드)`
  - `뉴트럴 다크`
- **배치 & 보기 옵션**:
  - `3열 × 2행` / `2열 × 3행 (인게임 배열)`
  - `능력 + 실능/SP 모두 표시` / `능력만 표시 (인게임형)`
  - `메가진화 폼 표시` / `기본 폼 표시`
  - 상단 배너(`파티명` / `설명`) 표시 On/Off

### 5. 브라우저 자동 저장 · 모바일 반응형 · 전체화면 · 16:9 PNG 저장
- 첫 방문 시에는 빈 상태로 시작하며, 입력한 파티·스샷 인식 내역(`[능력]`/`[스테이터스]`)·배너 문구·테마/언어 등 설정은 브라우저 `localStorage`에 자동 저장되어 **새로고침 후에도 초기화되지 않고 그대로 유지**됩니다.
- **모바일 편집 최적화**: 모바일 화면에서는 편집 시 카드가 가로 1열 세로 스크롤 레이아웃으로 자동 전환됩니다.
- **전체화면 (`F`)** 모드로 시트 전체를 깔끔하게 확인할 수 있습니다.
- **`16:9 이미지 저장 (PNG)`** 버튼으로 데스크톱·모바일 모두 동일한 고해상도(`2880×1620`, 고정 `16:9` 비율) PNG 이미지를 빠르게 다운로드합니다.

## 빠른 사용 방법

1. 게임 내 **`[능력]` / `[스테이터스]` 스샷을 `Ctrl+V`로 붙여넣거나**(또는 **`스샷 입력`** 버튼 클릭), **`쇼다운 입력 / 파일 열기`**로 텍스트/`.txt` 파일을 불러옵니다.  
   또는 **새 파티 짜기**(**개별 포켓몬 편집**)에서 슬롯별로 직접 포켓몬을 추가합니다.
2. 상단 컨트롤에서 **파티명 / 설명**, **테마**, **그리드 배열**, **표시 언어**, **메가진화 표기 방식**을 원하는 대로 맞춥니다.
3. 완료되면 **`16:9 이미지 저장 (PNG)`**을 눌러 이미지를 저장하거나 **`쇼다운 복사`**로 팀 텍스트를 복사합니다.

## 파일 구성

| 파일 | 설명 |
| :--- | :--- |
| `index.html` | 메인 레이아웃, 상단 컨트롤 바, 스샷 OCR · 쇼다운 입력 및 개별 편집 모달 |
| `styles.css` | 테마 스타일, 카드 그리드, OCR 모달, 모바일 1열 반응형 및 PNG 내보내기 스타일 |
| `app.js` | 시트 렌더링, 스샷 OCR 연동(`Ctrl+V`/드래그), SP 슬라이더, 네이티브 Canvas 2D 고속 PNG 렌더링(폴백: `html2canvas`) 및 `localStorage` 저장 |
| `core.js` | Lv.50 6V + SP 실능 계산, 한·일·영 쇼다운 파싱/내보내기, 메가진화 폼 변환 |
| `pokemon-data.js` | 포켓몬·기술·도구·특성 다국어 데이터셋 및 도구 아이콘 스프라이트 데이터 |
| `ocr-engine.js` | 스샷 카드/탭 감지, 한·일·영 퍼지 매칭, Lv.50 SP 교차검증, 쇼다운 변환 클라이언트 |
| `ocr-worker.js` | ONNX Runtime Web WASM 기반 로컬 PaddleOCR 추론 및 CTC 디코딩 웹 워커 |
| `models/`, `ort/`, `data/` | PP-OCRv5 인식 모델·사전, ONNX WASM 런타임, 챔피언스 규칙 DB |
